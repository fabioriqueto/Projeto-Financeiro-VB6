# 💼 Sistema Financeiro — Visual Basic 6

Sistema desenvolvido por **Fábio Alexandre Riqueto**, originalmente no ano de **2000**, para utilização em uma instituição financeira.

O projeto é disponibilizado neste repositório como parte do meu portfólio profissional e acadêmico, preservando um exemplo real da minha experiência no desenvolvimento de sistemas empresariais e financeiros.

## 📌 Sobre o projeto

O sistema foi desenvolvido para apoiar operações de uma instituição financeira que trabalhava com **financiamentos, empréstimos e operações envolvendo cheques**, atendendo tanto **pessoas físicas quanto pessoas jurídicas**.

Além do desenvolvimento da aplicação, o projeto envolveu a estruturação do banco de dados, implementação das regras de negócio, consultas, pesquisas e geração de relatórios.

O projeto representa uma parte da minha experiência profissional com desenvolvimento de sistemas personalizados para processos específicos de cada empresa.

## ⚙️ Tecnologias utilizadas

- Visual Basic 6
- Microsoft Access
- SQL
- Windows

## 💰 Contexto financeiro

Entre os processos contemplados pelo sistema estavam operações relacionadas a:

- Financiamentos;
- Empréstimos;
- Operações envolvendo cheques;
- Cadastro de pessoas físicas e jurídicas;
- Controle das informações das operações;
- Consultas e pesquisas;
- Geração de relatórios.

## 🗂️ Funcionalidades

### Cadastro

- Clientes;
- Cheques;
- Documentos;
- Informações relacionadas às operações financeiras.

### Consultas e pesquisas

- Localização de registros;
- Pesquisa de informações cadastradas;
- Filtros para facilitar a consulta aos dados.

### Relatórios

- Geração de relatórios;
- Impressão das informações;
- Relatórios personalizados de acordo com as necessidades da operação.

## 🧠 Regras de negócio

O desenvolvimento do sistema exigiu a compreensão dos processos utilizados pela instituição financeira e a transformação dessas necessidades em funcionalidades de software.

A aplicação foi estruturada considerando diferentes tipos de operações financeiras e os dados necessários para seu controle e acompanhamento.

Essa experiência faz parte da minha trajetória no desenvolvimento de sistemas orientados a **regras de negócio**, trabalhando diretamente com necessidades específicas dos usuários e das empresas.
